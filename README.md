# Ninja Run (iOS)

Физический платформер в духе N: инерционный бег, прыжки от стен, смерть от сильного удара,
золото добавляет время, переключатель открывает дверь выхода.

Swift + SpriteKit, без сторонних зависимостей. iOS 16+, iPhone и iPad, альбомная ориентация.

## Запуск
Открыть `NinjaRun.xcodeproj` в Xcode → выбрать симулятор или своё устройство → Run (⌘R).
Для устройства: в Signing & Capabilities выбрать свою команду (Team).

## Управление
- Левая половина экрана — ◀ ▶ (можно вести пальцем)
- Правая половина — прыжок (удержание = выше)
- У стены: прыжок отталкивает; зажатое направление к стене — скольжение
- В симуляторе работает клавиатура: стрелки / A D, прыжок — пробел / ↑ / W / Z

## Файлы
- `Geometry.swift` — тайлы, коллизии круга с полигонами, raycast
- `Player.swift` — физика ниндзя (константы в `Player.Tuning`) и анимация фигурки
- `Entities.swift` — золото, мины, переключатель, дверь, ключ, батут, дроны, турели, ракеты
- `GameScene.swift` — игровой цикл (фиксированный шаг 60 Гц), HUD, сенсорное управление
- `MenuScenes.swift` — меню и выбор уровней
- `Levels.swift` — уровни в ASCII (легенда в начале файла), 31×23 клетки
- `Localization.swift` — все тексты на 7 языках (en, ru, es, de, it, fr, zh); язык по умолчанию — системный, переключается в меню
- `Sound.swift` — синтезированные звуковые эффекты
